## About me

I build web applications, reusable components and tools for product teams. I have **10+ years of experience** working across frontend architecture, implementation, testing and delivery.

Previously at **Dialpad, Rocketgenius, Modern Tribe and Despegar**. I also co-founded **GreenBit**, where I build products with React, Next.js and Node.js.

I like working on the foundations behind a good interface: how components fit together, how state flows, and how to make the code easier for the next person to work with.

`React` `JavaScript / TypeScript` `Vite` `Tailwind CSS` `Vitest` `MSW`

The API behind Token Dashboard: token management, tenant and project boundaries, authentication, role-based permissions and API documentation.
